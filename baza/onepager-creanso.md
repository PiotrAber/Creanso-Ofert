# One pager Creanso - koncepcja

## Cel

Stworzyc atrakcyjny, interaktywny material ofertowy, ktory mozna wykorzystac jako:

- landing page dla oferty Creanso,
- ekran do rozmowy z klientem,
- one pager wysylany po spotkaniu,
- baza pod prezentacje ofertowa,
- prototyp aplikacji ofertowej.

## Glowna idea

Oferta nie jest lista uslug. Ma prowadzic klienta przez decyzje:

1. Co dzis ogranicza wynik?
2. Jaki model wspolpracy proponuje Creanso?
3. Z jakich modulow sklada sie zakres?
4. Ktory wariant ma najwiecej sensu?
5. Jaki jest nastepny krok?

## Struktura strony

1. Hero
2. Opis w skrocie
3. Model wspolpracy
4. Trzy bloki argumentacyjne
5. Interaktywny konfigurator zakresu
6. Warianty oferty
7. Plan pierwszych 90 dni
8. Podsumowanie
9. CTA
10. Dane kontaktowe

## Co jest interaktywne

- wybor glownego celu klienta,
- wybor etapu klienta,
- wlaczanie i wylaczanie modulow wspolpracy,
- automatyczna rekomendacja wariantu: Start, Growth albo Scale,
- generowanie zarysu oferty do skopiowania.

## Do uzupelnienia przed uzyciem z klientem

- dane kontaktowe,
- ceny lub model wyceny,
- przyklady klienta / branzy,
- konkretne KPI,
- case studies,
- logo / identyfikacja wizualna,
- link do strony Creanso,
- realny zakres poza oferta.

## Plik

Glowna wersja strony znajduje sie w:

`index.html`

Jest to samodzielny plik HTML z CSS i JavaScriptem, bez zewnetrznych zaleznosci.
